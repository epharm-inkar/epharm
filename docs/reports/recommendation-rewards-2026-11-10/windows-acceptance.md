## Границы среды

Используется отдельная Windows DEMO без сетевых адаптеров, настоящий кандидат
backend и отдельный PostgreSQL на Mac. Синтетический сотрудник и отдельная акция
не относятся к production. Мобильное приложение не проверяется. Loopback/QGA
мост возвращает настоящий HTTP-ответ backend, не подставляет успешные результаты
и не является средством измерения пропускной способности.

В первом опыте не выдавалось положительное доказательство корзины: в DEMO были
три открытые сессии одного компьютера. Исправление не выбирает произвольную
сессию: возраст heartbeat должен быть от 0 до менее 300 секунд, две живые
локальные сессии остаются неоднозначностью. На повторе транспорт тестового моста
получал ошибки sharing violation, затем Windows сообщила о нехватке системных
ресурсов при записи штатного лога. VM остановлена штатно и перезапущена; база
сохранена. Причина исчерпания ресурсов не объявляется доказанной.

В UTM 4.7.5 принудительная отмена chunked CLI file transfer способна оставить
гостевой handle открытым. Для повторного стенда QGA transfer сериализован,
увеличен только технический deadline CLI (30 секунд), опрос сокращён до 2/с;
первый timeout прекращает дальнейший QGA I/O. Денежные ограничения свежести
источника и печати, 120 секунд на добавление товара и серверная проверка оплаты
не ослаблялись.
